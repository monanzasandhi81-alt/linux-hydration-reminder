## Run

From the project directory:

```bash
bash main.sh
```

## Features

- Log water intake
- Show today's total and goal progress
- List days when the goal was met
- Display a 7-day text chart
- Show reminder schedule
- View saved data
- Back up water log
- View recent activity log

Daily goal is configured as 2000 ml in `lib/functions.sh`.

## Project Files

- `main.sh` – Main Bash program
- `lib/functions.sh` – Project functions
- `data/` – Water intake data
- `logs/` – Activity logs
- `reports/` – Reports
- `backups/` – Backup files
