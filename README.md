# Linux Hydration Reminder

A Bash-based hydration tracking project.

## Run
From the project directory:
```bash
bash main.sh
```

## Features
- Log water intake
- Show today's total and goal progress
- List days when the goal was met
- Display a 7-day text chart
- Show reminder schedule
- View saved data
- Back up water log
- View recent activity log

Daily goal is configured as 2000 ml in `lib/functions.sh`.

Note: This archive was assembled from the `main.sh` code shared in chat and the uploaded `lib/functions.sh` content. Empty data/log/report/backup folders are included; your original Webminal records are not included.
